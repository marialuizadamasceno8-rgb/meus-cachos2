
# MEU CACHOS

Sistema de gerenciamento de uma loja de produtos para cabelos cacheados.

## Sobre o projeto

O Meu Cachos é um sistema desenvolvido em Java que permite visualizar produtos, pesquisar itens, filtrar categorias, gerenciar um carrinho de compras e avaliar produtos.

## Funcionalidades

- Listagem de produtos.
- Filtro por categoria.
- Filtro por faixa de preço.
- Busca por nome.
- Adição e remoção de produtos do carrinho.
- Cálculo de subtotal e descontos.
- Avaliação de produtos.
- Histórico de avaliações.
- Organização alfabética dos produtos.

## Tecnologias utilizadas

- Java
- Scanner
- Arrays
- ArrayList e List
- Tratamento de exceções
- Manipulação de arquivos

## Como executar

1. Abra o projeto no Visual Studio Code.
2. Abra o terminal na pasta principal.
3. Compile o programa:

```bash
javac -d bin src/MeuCachos.java
```

4. Execute:

```bash
java -cp bin MeuCachos
```
